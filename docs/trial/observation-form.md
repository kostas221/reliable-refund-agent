# Observation form

For the observer: one copy per session, saved as `runs/live-trial/P<n>.md` (kept out of git). Write what happened and
what was said, word for word where possible; interpretation goes in the last section only.

```
Participant: P_    Role: customer / staff    Support experience: yes / no
Date:              Commit:                   Owner played: staff / customer
Log folders (one per task): runs/live-...
```

## Each task

Copy this block for tasks 1 to 4.

```
Task _ (scenario D__)
Done without help / with a hint / not done:
Hints given, word for word, and when:
Information the participant gave twice (what, and why it was asked again):
Used the order list's item choice: yes / no
Typed "yes" in the chat instead of pressing a button: yes / no
Pressed Talk to a person: yes / no
Something the participant misread (quote):
Anything that matches a stop rule (protocol.md):
Time from first message to the end:
```

## The questions after each task

Asked as written, after the task, before the next card. Write the answer, not a summary.

- **Task 1, after the assistant's answer about the controller:** "What did the shop tell you about the controller?"
- **Task 1, after Confirm, before the staff decision:** "What happens now? Has any money been sent?"
- **Task 1, after the receipt:** "Where is the money going, and when will you have it?"
- **Task 2:** "Is the request what you wanted? Was anything unclear about which item it is for?"
- **Task 3:** "Can you get your money back? What would you do next?"
- **Task 4, after the waiting notice and before the email:** "What happens now? How will you hear back?"

## The staff session

After each case the participant handled:

- "Do you have what you need to decide? What would you check that you cannot see here?"
- Task 4: the email the participant wrote, word for word.
- At the end, only with support experience: "How would you handle these cases at work today? Which steps does this
  screen save you, and which does it add?"

## At the end of the session

- "What was the hardest moment?"
- "Was anything confusing or surprising?"
- "What would you change first?"

## The observer's notes

Kept apart from what was seen and said: the observer's reading, and which problems look like defects.
